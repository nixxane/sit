sit

A small, fast IPTV player. One C binary, no Electron, no database, no telemetry. Keyboard first, mouse friendly.

Download for Windows All downloads Source

Windows: run the installer and open sit from the Start menu. On first start, sit asks for your provider details. Linux, macOS and FreeBSD: build from source.

What it does

  • Xtream CodesLive TV, movies and series with posters, details and episodes.
  • M3U and XMLTVPlaylists from a URL or a file, guide from .xml or .xml.gz.
  • Programme guideNow and next, a full guide page, and catch-up playback.
  • Plays everythinglibmpv inside the window: any codec, HLS, TS, hardware decoding.
  • Yours to keepFavorites, recently watched, and resume position for movies and series.
  • SearchAcross live, movies and series at once.
  • Right to left textArabic and Hebrew are shaped and ordered correctly.
  • SmallC99, plain makefile, configured by editing config.h. Light and dark themes.

Keys

EnterPlay or open. Again on what plays: full view.
/Search
fAdd or remove a favorite
eProgramme guide for a channel
F11Fullscreen
- = mVolume down, up, mute
rReload the list

The full list is in the man page, and the app shows key hints on screen.

Build from source

You need SDL2, libmpv, libcurl and zlib.

git clone https://github.com/nixxane/sit
cd sit
make
sudo make install

On Windows, build in an MSYS2 UCRT64 shell with make OS=win.

Your sources

Sources live in a tab-separated file: %APPDATA%\sit\sources on Windows, ~/.config/sit/sources elsewhere.

name  xtream  http://provider:8080  username  password
name  m3u     http://host/list.m3u   [guide.xml]

sit does not provide any channels or content. You need your own provider.
